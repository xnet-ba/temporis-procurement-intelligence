# Vizija TPI

TPI je modularni AI ekosistem za javnu nabavu u RH: vještine + MCP + aplikacije + znanje s citatima.
Nije chatbot: svaki odgovor nosi izvor, član/stav/tačku, datum i status važenja, nivo pouzdanosti.

Korisnici: naručitelji, ponuditelji, pravnici, konsultanti, certificirani stručnjaci.
Načelo: stručni komentar se nikad ne predstavlja kao zakon; nepoznato se označava kao nepoznato.
