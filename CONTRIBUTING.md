# CONTRIBUTING

1. Prije veće izmjene: plan + mali provjerljivi koraci.
2. Prije izmjene postojećih fajlova: commit ili branch.
3. Poruke commita: `faza0: kratak opis` / `skill(bjn-knowledge): ...` / `mcp: ...`.
4. Bez tajni u repozitoriju (vidi SECURITY.md). Bez scrapinga zaštićenog sadržaja.
5. Svaka komponenta: test ili dokumentovan razlog zašto test nije moguć.
6. AI pravila pouzdanosti (izvor, član, datum važenja) su obavezna za knowledge/skills/mcp.
7. Faza je gotova tek kad su kriteriji iz ROADMAP-a provjereni.
